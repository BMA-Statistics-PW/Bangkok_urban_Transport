# หมายเหตุกำกับข้อมูล (Data Notes)

เอกสารนี้บันทึกข้อควรระวังและความผิดปกติที่ทราบของชุดข้อมูลใน `dashboard-template/data/`
เพื่อความโปร่งใสและการตีความที่ถูกต้อง (ข้อมูลราชการ — ไม่แก้ไขค่าจริงโดยไม่มีแหล่งอ้างอิงยืนยัน)

## ข้อมูลไม่ครบปีที่ต้องระวัง

### BRT ปี 2567 — ข้อมูลเฉพาะ 2 เดือน (ยืนยันสาเหตุแล้ว)
- ค่าที่บันทึก: **476,934 เที่ยว-คน** — เป็น **ค่าที่ถูกต้อง** แต่ **ไม่ครบทั้งปี**
- ตรวจสอบชีต "BRT" (รายเดือน) ในไฟล์ต้นทางแล้วพบว่า ปี 2567:
  - **มกราคม–ตุลาคม = "-" (ไม่มีข้อมูล) เนื่องจากเป็นช่วงปรับเปลี่ยนระบบเดินรถ**
  - พฤศจิกายน = 241,657 · ธันวาคม = 235,277
  - **รวม = 241,657 + 235,277 = 476,934** (มีข้อมูลจริงแค่ 2 เดือน)
- จึงต่ำกว่าปีข้างเคียงราว 6 เท่า (2566 = 3,478,056 · 2568 = 2,658,903) เพราะขาด 10 เดือน
  ไม่ใช่ค่าผิด และ **ไม่ควรนำไปเปรียบเทียบตรงกับปีที่มีข้อมูลครบ**
- **สถานะ:** คงค่าเดิม + ทำเครื่องหมาย "ไม่ครบปี (ช่วงปรับเปลี่ยนระบบเดินรถ)"
  ใน `js/main.js` → `businessRules.brtPartialYears`

## เงื่อนไขเชิงธุรกิจที่ควรทราบ (ปกติ ไม่ใช่ error)

- **ปี 2563–2564:** ได้รับผลกระทบจาก COVID-19 ตัวเลขต่ำผิดปกติ ไม่ควรนำไปเทียบตรงกับปีปกติ
- **ปี 2556–2559:** ข้อมูล "เรือโดยสาร" เป็นเฉพาะเรือข้ามฟาก
- **แถวสรุป/หมายเหตุ** ใน CSV (รวม, ค่าเฉลี่ย, สัดส่วน, ปริมาณผู้เดินทาง, หมายเหตุ, URL, ลิขสิทธิ์)
  ถูกกรองออกอัตโนมัติจากชุดข้อมูลระบบขนส่งโดย `transformReportRows()` ใน `js/main.js`

## การล้างข้อมูลอัตโนมัติ (Auto-clean)

ไฟล์ CSV ถูกดึงใหม่ทุกสัปดาห์จาก Google Sheets โดย `scripts/update_transport_csv.sh`
หลังดาวน์โหลดจะรัน `scripts/normalize_transport_csv.mjs` เพื่อล้าง **เฉพาะแถวหัวตาราง (header)**:

- คอลัมน์ปีที่มีข้อความปนเปื้อน เช่น `"หน่วย: ล้านคน-เที่ยวต่อปี ปี 2566"` → `"ปี 2566"`
- ตัดช่องว่างส่วนเกินในหัวคอลัมน์

**แถวข้อมูลจะไม่ถูกแก้ไขใด ๆ** (ค่าตัวเลขคงเดิมทุกจุด) และสคริปต์ทำงานซ้ำได้โดยผลลัพธ์คงที่ (idempotent)
